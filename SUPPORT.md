# Support

## Usage questions

Before asking for help, check the [README](README.md), confirm that Python 3.11
or newer is installed and run:

```bash
python -m pytest -q
```

For reproducible bugs, open a bug report and include your operating system,
Python version, the command you ran and a sanitized error message.

## Feature proposals

Use the feature request template and explain the workflow problem first. A
small example is more useful than a broad feature list.

## Security issues

Do not post vulnerabilities, credentials, private prompts or customer data in
public issues. Follow the private reporting instructions in
[SECURITY.md](SECURITY.md).
